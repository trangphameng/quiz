## Đăng lên GitHub Pages
1. Tạo repository mới trên GitHub (ví dụ `manners-reading`).
2. **Add file → Upload files** → kéo thả **toàn bộ nội dung** thư mục này (index.html, L01–L12.html, thư mục images/) → **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, thư mục `/ (root)` → **Save**.
4. Sau 1–2 phút, link mục lục là `https://<tên-tài-khoản>.github.io/manners-reading/`
   - Link từng bài: `.../manners-reading/L05.html`
